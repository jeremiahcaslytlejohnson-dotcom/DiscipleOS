---
name: Guided Climb set boundaries
description: Product rules for independently completable Guided Climb sets.
---

Guided Climb Set 1, “Find Your Footing,” is an optional 27-day plan that must finish on its own. Do not automatically chain a later set. After completion, Mountain Rhythm and Free Climb are optional choices.

**Why:** The user wants readers to be able to stop after Set 1 or choose another path; Set 2 is explicitly deferred.

**How to apply:** Keep future curated sets separate from Set 1 completion, and do not invent or silently change reading assignments.
