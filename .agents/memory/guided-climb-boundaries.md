---
name: Guided Climb set boundaries
description: Product rules for independently completable Guided Climb sets.
---

Guided Climb Set 1, “Discover Scripture,” is an optional 27-day plan that must finish on its own. Keep the existing `find-your-footing` slug and saved plan metadata compatible. Do not automatically chain a later set. After completion, Mountain Rhythm and Free Climb are optional choices.

**Why:** The user approved “Discover Scripture” as the user-facing name while preserving existing plan references, and wants readers to be able to stop after Set 1 or choose another path; Set 2 is explicitly deferred.

**How to apply:** Keep the stable slug and recognize existing saved Set 1 plans by metadata while showing the approved display name. Keep future curated sets separate from Set 1 completion, and do not invent or silently change reading assignments.

## Introductory screen
Show the Discover Scripture introduction before the first Guided Climb start; returning readers should continue their saved plan directly, with the overview available from that plan.

**Why:** The user asked for a brief orientation before Day 1 and a way to revisit it without interrupting repeat visits or existing progress.

**How to apply:** Keep the introduction separate from plan creation; if Set 1 already exists, its primary action returns to Today’s Walk rather than creating or resetting a plan.
