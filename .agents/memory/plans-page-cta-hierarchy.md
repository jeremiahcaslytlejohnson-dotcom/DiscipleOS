name: Plans-page CTA hierarchy
description: User intent for distinguishing Free Climb plan management from optional Guided Climb discovery.
---

When users already have plans, keep “Add plan” as the sole prominent primary action. Keep Guided Climb discoverable as a clearly optional, unobtrusive text link, separate from plan cards; do not imply that a Free Climb is incomplete or automatically add a Guided plan. Preserve the existing intro flow and zero-plan chooser.

**Why:** The user stated that creating a custom plan such as Psalms + Proverbs is already a valid Free Climb, and the Plans page must not imply that Guided Climb is a required next step.

**How to apply:** Preserve this hierarchy when changing the Plans header or adding alternate-path discovery. Do not change plan classification, create behavior, curriculum, or the empty-state chooser to solve CTA confusion.
