---
name: DiscipleOS stabilization freeze
description: Scope rule for Replit task suggestions during the DiscipleOS stabilization effort.
---

Until all agreed DiscipleOS stabilization work is complete, verified, and explicitly approved, do not generate, create, queue, recommend, or surface new Replit suggested feature tasks or optional improvements. Work only on the approved stabilization scope. Report an actual blocking bug or security/data-integrity issue as a blocker in the stabilization status instead of expanding scope.

**Why:** the user explicitly requested a suggestion freeze until the stabilization work is cleaned up.

**How to apply:** do not create follow-up tasks or optional improvement suggestions until the user explicitly approves completion of the stabilization effort.
